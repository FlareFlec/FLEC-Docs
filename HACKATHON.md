# FLEC Hub — Flare Hackathon 2026

## Overview

FLEC Hub is the hackathon implementation of FLEC’s Spanish-first onboarding and educational vision for the Flare ecosystem.

The project helps Spanish-speaking users progress from ecosystem discovery to guided education, secure onboarding, and practical learning experiences within the Flare ecosystem.

This document distinguishes the project foundation that existed before the hackathon from the implementation work completed during the program.

---

## Hackathon Objective

Build a bilingual, guided educational experience that demonstrates how FLEC can help Spanish-speaking users:

- understand essential Flare concepts;
- experience a beginner-friendly cinematic audiovisual guide in Spanish;
- learn safer wallet practices;
- complete a structured onboarding journey;
- experience a practical Coston2 interaction;
- continue their journey toward deeper participation in the Flare ecosystem.

## Development Principles

The implementation is guided by the following principles:

- Spanish-first accessibility
- Education before interaction
- Security before wallet actions
- Meaningful integration with the Flare ecosystem
- Clear separation between demo functionality and future roadmap
- Reusable implementation rather than one-time presentation code
- Controlled development milestones
- Cost-conscious testing and implementation

---

## Technical Direction

FLEC Hub is being developed as a modular guided application rather than a standalone landing-page demo.

The current foundation includes:

- bilingual content support;
- reusable guidance components;
- persistent local experience state;
- progressive learning sections;
- a reusable audiovisual guidance system;
- configurable guidance presentation behavior.

A cinematic audiovisual guide is being developed as part of the hackathon MVP.

Wallet interaction, Coston2 participation, and additional guided experiences remain in development and are not presented as completed functionality.

Sensitive implementation details and internal development resources are not published in this repository.

## Future Beyond the Hackathon

The hackathon MVP is the first implementation milestone toward a broader Spanish-first adoption layer for Flare.

FLEC is designed to help Spanish-speaking users discover, understand, and confidently engage with projects across the Flare ecosystem.

Future iterations may include:

- educational modules for Flare builders and dApps;
- localized onboarding experiences;
- expanded guided learning content;
- ecosystem discovery;
- community learning initiatives;
- additional guided integrations across Flare.

Future functionality is not presented as part of the current hackathon implementation unless explicitly marked as completed.
