# FLEC

FLEC is a community-driven initiative created to help Spanish-speaking users across LATAM discover Flare, understand the ecosystem, and participate in a more accessible and beginner-friendly way.

Our long-term vision is to build a Spanish-first community and educational hub for Flare, combining education, safer onboarding, wallet security, community programs, future NFT experiences, and practical pathways for users to discover and engage with projects across the ecosystem.

## FLEC Hub

FLEC Hub is the first working implementation of this broader vision.

Originally developed during the Flare hackathon, FLEC Hub introduces a beginner-friendly educational experience focused on:

- Flare ecosystem education
- Wallet safety
- Guided onboarding
- Community participation
- Future learning and reward systems
- Future NFT progression experiences

The hackathon version is an early educational prototype. Several features described in the documentation remain part of the future roadmap and are not yet active in production.
