## About FLEC

FLEC (Flare • LATAM • Evolution • Community) is a community-driven initiative built within the Flare ecosystem.

Focused on participation, education, digital collectibles, and future interactive experiences, FLEC aims to strengthen community engagement while supporting the growth of the broader Flare ecosystem.

Built on four core pillars:

- **Flare** – Built on Flare Network.
- **LATAM** – Rooted in Latin America and open to a global audience.
- **Evolution** – Focused on growth, innovation, and adaptation.
- **Community** – Driven by participation, collaboration, and shared contributions.
